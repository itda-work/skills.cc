---
title: "account-file 활용 가이드 (Claude Code)"
---

itda-cc 스킬(메일·일정·DART·ECOS)이 읽는 **계정 파일**을 대신 만들고, 열고, 검사하고, 고쳐 주는 스킬입니다.
비밀번호는 대화창에 한 번도 나오지 않습니다 — 여러분이 편집기에서 직접 적고, Claude 는 "몇 번째 줄이 틀렸다" 만 봅니다.

---

## 처음 설정하기

1. Claude 에게 **"계정 파일 만들어줘"** 라고 말합니다. 홈 폴더에 `계정.toml` 이 생깁니다.
2. **"계정 파일 열어줘"** 라고 말합니다. Windows 는 메모장, macOS 는 텍스트 편집기로 열립니다.
3. 쓸 계정의 `"..."` 만 내 값으로 바꾸고 저장합니다. **따옴표는 지우지 마세요.**
4. **"계정 파일 검사해줘"** 라고 말합니다. "쓸 수 있는 계정: naver" 처럼 나오면 끝입니다.

```toml
[naver]
메일 = "me@naver.com"
앱비밀번호 = "ABCD1234EFGH"

# ── 아래는 예시입니다. 쓰지 않으면 그대로 두세요. ──

[gmail.회사]
메일 = "..."
앱비밀번호 = "..."
보내는이름 = "..."      # 받는 사람에게 보일 이름 (선택)
```

- `"..."` 로 남은 칸과 묶음은 **없는 것**으로 봅니다. 예시를 지우지 않아도 됩니다.
- 같은 서비스 계정이 둘이면 `[gmail.회사]`·`[gmail.개인]` 처럼 점 뒤에 이름을 붙입니다. 그러면 "회사 Gmail 로 보내줘" 라고 부를 수 있습니다.
- 메일만 채우고 앱비밀번호를 비워 두면 그 계정은 쓰지 않고 알려 드립니다.

## 이렇게 말하면 됩니다

| 말 | 하는 일 |
|---|---|
| "계정 파일 만들어줘" | 틀을 만듭니다. 이미 있으면 건드리지 않습니다 |
| "계정 파일 열어줘" | 편집기로 엽니다 |
| "계정 파일 검사해줘" | 틀린 줄 번호, 쓸 수 있는 계정, 건너뛴 묶음을 알려 줍니다 |
| "계정 파일 고쳐줘" | 따옴표 빠짐 같은 확실한 실수만 고칩니다. 원본 사본을 옆에 남깁니다 |
| "계정 파일을 새 형식으로 옮겨줘" | 예전 `.env` 를 `계정.toml` 로 옮깁니다 |

## 자주 하는 실수

- **닫는 따옴표를 지웠다** — `메일 = "me@naver.com` → "고쳐줘" 가 줄 끝에 따옴표를 붙입니다.
- **macOS 텍스트 편집기가 따옴표를 “ ” 로 바꿨다** — "고쳐줘" 가 일반 따옴표로 바꿉니다. 아예 막으려면 텍스트 편집기 메뉴
  `편집 → 대치 → 스마트 따옴표` 를 끕니다.
- **같은 칸을 두 번 적었다** — 어느 쪽이 맞는지 Claude 가 정할 수 없어 줄 번호만 알려 드립니다. 하나를 지우세요.
- **고친 뒤 생긴 `계정.toml.고치기전-….bak`** — 고친 결과가 맞으면 지우세요. 그 사본에도 비밀번호가 들어 있습니다.

## 알아 두기

- 계정 파일은 **하나만** 읽습니다. 현재 폴더 → 홈 폴더 순으로 처음 찾은 것 하나입니다. 같은 폴더에 `.env` 와 `계정.toml` 이
  함께 있으면 어느 계정을 쓸지 몰라 멈춥니다 — 하나만 남기세요.
- 회사 메일(`SMTP_HOST` 등)·회사 CalDAV 는 아직 `계정.toml` 에 칸이 없습니다. 그런 계정은 `.env` 를 계속 쓰세요.
- `계정.toml` 은 한글 칸 이름에 따옴표를 붙이지 않아도 되는 itda-cc 전용 꼴입니다. 다른 TOML 도구로는 열리지 않을 수 있습니다.
- `계정.toml` 을 읽으려면 Python 3.11 이상이 필요합니다(`.env` 는 3.10 도 됩니다).
- 이 파일을 남에게 보내거나 공유 폴더(클라우드 동기화 폴더 포함)에 두지 마세요.
