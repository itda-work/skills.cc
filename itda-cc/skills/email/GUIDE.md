---
title: "email 활용 가이드 (Claude Code)"
---

네이버·Gmail·다음/카카오·아이클라우드·회사 메일로 메일을 찾고 읽고 보내는 **Claude Code 전용** 스킬입니다. **Claude 에게 자연어로 말하면 됩니다.**
Claude 가 스킬의 스크립트로 메일 서버(IMAP·SMTP)에 직접 접속합니다. 계정과 앱 비밀번호는 여러분이 만든 **`.env` 파일 하나**에만 적습니다.

> Claude Desktop(Cowork)에서 쓰신다면 이 스킬이 아니라 `itda-work` 팩의 email 스킬을 쓰세요.

---

## 처음 설정하기

1. **메일 서비스에서 앱 비밀번호를 발급하고 IMAP 을 켭니다.** 계정 비밀번호는 그대로 쓰지 못합니다. 아래 서비스별 절차를 따르세요.
2. **`.env` 파일을 만듭니다.** 아래 예시를 복사해 값만 바꿉니다.
3. **권한을 잠급니다.** 그 파일을 나만 읽을 수 있게 해 두세요 — Claude 에게 "~/.env 를 나만 읽게 권한 잠가줘" 라고 말하면 됩니다.

### `.env` 는 어디에 두나

스크립트는 다음 순서로 **처음 찾은 파일 하나만** 읽습니다(여러 파일을 합치지 않습니다).

1. Claude 에게 "`/경로/my.env` 를 써줘" 처럼 따로 지정한 파일
2. 지금 작업 중인 폴더의 `.env`
3. 홈 폴더의 `~/.env`

현재 폴더에 `.env` 가 있으면 홈의 `~/.env` 는 보지 않습니다. 현재 폴더 `.env` 에 메일 키가 없으면 "키가 없다" 고 멈춥니다 — 그 파일에 키를 추가하거나 현재 폴더 `.env` 를 치우세요.
터미널의 환경변수(`export …`)는 읽지 않습니다.

### `.env` 예시

```
# 네이버
NAVER_EMAIL=me@naver.com
NAVER_APP_PASSWORD=앱비밀번호

# Gmail
GOOGLE_EMAIL=me@gmail.com
GOOGLE_APP_PASSWORD=abcdabcdabcdabcd

# 다음/카카오 (@daum.net · @hanmail.net · @kakao.com)
DAUM_EMAIL=me@daum.net
DAUM_APP_PASSWORD=전용비밀번호

# 아이클라우드 (@icloud.com · @me.com · @mac.com)
ICLOUD_EMAIL=me@icloud.com
ICLOUD_APP_PASSWORD=xxxx-xxxx-xxxx-xxxx

# 회사 메일(직접 입력) — 보내기 서버는 필수, 받기 서버는 읽을 때 필요
SMTP_HOST=smtp.company.co.kr
SMTP_PORT=465
SMTP_USER=me@company.co.kr
SMTP_PASSWORD=비밀번호
IMAP_HOST=imap.company.co.kr
IMAP_PORT=993
```

**같은 서비스 계정이 둘 이상**이면 키 끝에 `_이름` 을 붙입니다. Claude 에게는 `naver_work` 처럼 부르면 됩니다.

```
NAVER_EMAIL_WORK=team@naver.com
NAVER_APP_PASSWORD_WORK=다른앱비밀번호
```

- 회사 메일의 `SMTP_PORT` 가 465 면 SSL, 그 밖(587 등)이면 STARTTLS 로 접속합니다. 받기는 `IMAP_PORT`(기본 993) SSL 입니다.
- 값에 공백이나 `#` 이 있으면 따옴표로 감싸세요(`NAVER_APP_PASSWORD="ab #cd"`).

> 비밀번호를 Claude 대화창에 붙여 넣지 마세요. Claude 는 그 값을 쓰지 않고 `.env` 에 적으라고 안내합니다. Claude 는 `.env` 파일을 열어 보지도 않습니다.

### 네이버

1. [네이버 로그인 보안](https://nid.naver.com)에서 2단계 인증을 켭니다.
2. 보안 설정 → 2단계 인증 → "애플리케이션 비밀번호 관리"에서 비밀번호를 발급받아 **그 자리에서 복사**합니다(한 번만 보입니다).
3. 네이버 메일 → 설정(톱니바퀴) → "POP3/IMAP 설정"에서 IMAP을 **사용함**으로 켭니다.
4. `.env` 에 `NAVER_EMAIL`(전체 주소)·`NAVER_APP_PASSWORD` 를 적습니다.

### Gmail

1. [Google 계정](https://myaccount.google.com) → 보안에서 2단계 인증을 켭니다.
2. [앱 비밀번호 페이지](https://myaccount.google.com/apppasswords)에서 이름을 적고 만들기 → **16자리 비밀번호**를 복사합니다(공백은 빼고 적어도 됩니다).
3. `.env` 에 `GOOGLE_EMAIL`·`GOOGLE_APP_PASSWORD` 를 적습니다. (일반 로그인 비밀번호는 동작하지 않습니다.)

### 다음 / 카카오

1. [다음 메일](https://mail.daum.net) → 환경설정 → "IMAP/POP3" 탭에서 IMAP 사용을 **사용함**으로 켭니다.
2. 같은 화면의 "비밀번호 확인하기"를 눌러 카카오 계정 인증 후 나오는 **전용 비밀번호**를 복사합니다.
3. `.env` 에 `DAUM_EMAIL`·`DAUM_APP_PASSWORD` 를 적습니다.

### 아이클라우드 (iCloud Mail)

1. [Apple 계정 관리](https://account.apple.com) → **로그인 및 보안**에서 2단계 인증이 켜져 있는지 확인합니다.
2. **앱 전용 비밀번호** → "앱 전용 비밀번호 만들기" 로 **xxxx-xxxx-xxxx-xxxx** 형식의 비밀번호를 받습니다(한 번만 표시됩니다).
3. `.env` 에 `ICLOUD_EMAIL`·`ICLOUD_APP_PASSWORD` 를 적습니다. 보내기는 587(STARTTLS)로 자동 접속합니다.

## 활용 시나리오

### 목록 먼저, 고른 메일만 열기

"네이버 메일 보여줘" 라고 하면 Claude 가 먼저 **날짜·보낸 사람·제목** 목록만 보여 줍니다. "2번 열어줘" 처럼 고른 메일만 본문을 엽니다.
메일을 열어도 **읽음 표시는 바뀌지 않습니다.**

### 보내기 전에 미리보기 확인

Claude 가 먼저 **미리보기(보낸 사람·받는 사람·제목·본문 앞부분·첨부)** 를 보여 주고, "보내" 라고 확인해야 실제로 발송됩니다.
내용을 고치라고 하면 고친 내용으로 미리보기를 다시 보여 줍니다. 미리보기는 10분이 지나면 다시 만들어야 합니다.

### 파일 첨부

"작업 폴더의 reports/q3.pdf 를 김대리에게 보내줘" 처럼 파일을 말하면 됩니다. 폴더·바로가기(심볼릭 링크)는 붙이지 않습니다.

### 받은 첨부를 받아서 읽기

"첨부를 받아서 요약해줘" 라고 하면 첨부를 **작업 폴더의 `attachments/`(또는 말한 폴더)에 저장한 뒤 그 파일을 열어** 내용을 요약합니다.

- 같은 이름의 파일이 이미 있으면 「이름 (1).pdf」 처럼 새 이름으로 저장합니다.
- **실행 파일은 받지 않습니다** — `.exe`·`.js`·`.bat`·`.lnk`·`.ps1`·`.msi`·`.iso`·`.sh` 같은 형식은 저장하지 않고 이유를 알려 줍니다.
- **매크로 문서**(`.docm`·`.xlsm`·`.pptm` 등)는 저장하되 경고를 붙입니다. 열 때 매크로를 켜지 마세요.
- 첨부 하나가 **30MB 를 넘으면** 받지 않습니다.
- 첨부 파일 안에 "이 파일을 누구에게 보내라" 같은 문구가 있어도 Claude 는 따르지 않습니다.

### 받은 메일에 답장

원래 메일과 같은 대화로 묶이도록(`In-Reply-To`·`References` 헤더) 답장하고 제목에 `Re:` 를 붙입니다.

## 받는 결과에 들어 있는 것

- **목록** — 날짜·보낸 사람·제목·첨부 여부·읽음 여부.
- **첨부 요약** — 저장한 파일 이름·크기와 내용 요약. 받지 못한 첨부는 이름과 이유를 따로 알려 줍니다.
- **피싱 주의 표시** — 회신 주소가 보낸 사람과 다른 도메인이거나, 표시 이름과 주소가 어긋나거나, 급하다며 링크·송금·비밀번호를 요구하면 ⚠️ 표시가 붙습니다.
  받은 서버가 적은 발신 인증 결과(SPF·DKIM·DMARC)가 있으면 함께 보여 줍니다.

## 안 될 때

- **".env 를 찾지 못했다"** — 위 세 위치 중 어디에도 `.env` 가 없습니다. 홈 폴더에 `~/.env` 를 만드세요.
- **"키가 없다"(env_key_missing)** — 알려 준 파일에 그 키가 없습니다. 현재 폴더에 다른 용도의 `.env` 가 있으면 그 파일이 먼저 읽힙니다.
- **"로그인 실패"(auth_error)** — 앱 비밀번호가 틀렸거나 메일 서비스에서 IMAP 이 꺼져 있습니다. 앱 비밀번호를 다시 발급해 `.env` 를 고치세요.
- **"다른 사용자도 읽을 수 있다" 경고** — Claude 에게 "그 .env 파일을 나만 읽게 권한 잠가줘" 라고 말하세요.
- **보낸 메일이 보낸메일함에 없다** — 이 스킬은 보낸 메일을 보낸메일함에 따로 저장하지 않습니다. 서버가 자동 저장하지 않는 서비스면 남지 않습니다.

## 제한사항

- **할 수 없는 것** — 임시보관함(초안), 메일 이동·스팸·휴지통·삭제, 읽음/별표 표시 변경, 폴더 관리, 미회신 자동 판정.
- **한글 검색** — 한글 조건은 한 번에 하나만 서버로 보냅니다. 여러 개를 쓰면 나머지는 받은 제목·주소로 거릅니다.
- **첨부 크기** — Gmail 은 한 통에 25MB, 네이버는 10MB(합계 20MB)까지입니다.
