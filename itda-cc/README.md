# itda-cc: Claude Code 전용 스킬팩

Claude Code(터미널·데스크톱 앱의 Code 탭)에서 쓰는 스킬 모음입니다. 스킬이 메일 서버·공공 API·요금 비교 API 에 **직접** 접속하므로
itda-hyve 를 설치하지 않아도 됩니다. Cowork 에서는 이 팩 대신 `itda-work`·`itda-gov`·`itda-travel` 팩을 쓰세요.

| 스킬 | 하는 일 | 계정 파일 묶음 (`.env` 키) |
|---|---|---|
| `account-file` | 계정 파일 만들기·열기·검사·고치기·`.env` 에서 옮기기 | 필요 없음 |
| `email` | 메일 찾기·읽기·첨부 저장·발송·답장·전달·임시보관함·정리(옮기기·휴지통·폴더)·미회신 찾기 | `[naver]`·`[gmail.회사]` 등 (`NAVER_EMAIL`·`NAVER_APP_PASSWORD` 등) |
| `calendar` | 네이버·iCloud·CalDAV 일정 조회·추가·수정·삭제 | 메일 계정 묶음 (직접 입력 CalDAV 는 `.env` 만) |
| `dart` | DART 전자공시 기업 정보·재무·공시 | `[dart] 키` (`DART_API_KEY`) |
| `ecos` | 한국은행 ECOS 경제통계 | `[ecos] 키` (`ECOS_API_KEY`) |
| `hotel-search` | 같은 호텔의 예약 사이트별 요금 비교·예약 링크·싼 날 달력 | 필요 없음 |

## 키는 계정 파일 하나에

계정 파일은 `계정.toml`(새 형식) 또는 `.env` 입니다. Claude 에게 **"계정 파일 만들어줘"** → **"계정 파일 열어줘"** 라고 말하면
틀을 만들고 편집기로 열어 줍니다. 쓸 계정의 `"..."` 만 내 값으로 바꾸고, **"계정 파일 검사해줘"** 로 확인하세요.

```toml
[naver]
메일 = "..."
앱비밀번호 = "..."

[gmail.회사]
메일 = "..."
앱비밀번호 = "..."

[dart]
키 = "..."
```

- 현재 폴더, 없으면 홈 폴더에서 **처음 찾은 계정 파일 하나만** 읽습니다. 같은 폴더에 `.env` 와 `계정.toml` 이 함께 있으면 멈춥니다. 셸 환경변수는 보지 않습니다.
- `"..."`·빈 값은 적지 않은 것으로 봅니다. 같은 서비스 계정이 둘이면 `[gmail.회사]` 처럼 묶음에 이름을 붙이고 "회사 Gmail 로" 처럼 부릅니다.
- `계정.toml` 은 한글 칸 이름에 따옴표를 붙이지 않아도 되는 **itda-cc 전용 꼴**이라 표준 TOML 이 아닙니다(다른 TOML 도구로는 열리지 않을 수 있습니다). 읽으려면 Python 3.11 이상이 필요합니다.
- `.env` 와 꼬리말 키(`GOOGLE_EMAIL_WORK`)는 계속 됩니다. 회사 메일(`SMTP_*`)·직접 입력 CalDAV 는 `.env` 로만 씁니다.
- 파일은 나만 읽게 두세요(`chmod 600`, 만들어 주는 틀은 이미 그렇습니다). 키 값은 대화창에 붙여 넣지 마세요.
